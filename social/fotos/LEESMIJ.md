# De foto's uit de werking

De echte foto's, om rond de middag te posten. Ze komen uit de plusklassen, de
pluswerkingen, Young Engineers en de kampen, en Kim gaf ze vrij voor sociale
media.

Alles in één keer: **`connectopia-fotos-werking.zip`** in deze map.

| Bestand | Wat je ziet |
| --- | --- |
| ballon-statische-elektriciteit | Een ballon boven papieren mannetjes, de armpjes komen omhoog |
| bouwpakket-in-genk | Een bouwpakket uitgespreid op de grote tafel in Genk |
| collage-project-plusklas | Vier beelden van hetzelfde project terwijl het gemaakt wordt |
| karton-uittekenen | De benen van het robotmannetje worden in het rood uitgetekend |
| lego-buggy-bouwen | Een tandwiel op zijn as zetten, met een tweede buggy ernaast |
| lego-robot-met-scherm | Een lego-wagen met een scherm van doorzichtige blokjes |
| materiaal-uitgesorteerd | De bakken materiaal, opnieuw uitgesorteerd voor dit schooljaar |
| papieren-figuurtjes-knippen | Drie uitgeknipte mannetjes, elk in een andere houding |
| patronen-tekenen | Braintraining: met twee handen tegelijk hetzelfde patroon tekenen |
| plusklas-de-katteket | De voorbereiding van de tentoonstelling, met een maquette van de kolonie |
| plusklas-mars-projecten | De maquettes van de maan- en de marskolonie, met kaartjes erbij |
| reuzenbellen-buiten | Een reuzenbel, langer dan het kind dat hem maakt |
| robot-van-karton-in-de-hand | Het kartonnen mannetje met scharnieren in de knieën |
| schaken-met-lego | Twee kinderen schaken op een nagebouwd Minecraft-schaakbord |
| schilderen-met-acryl | Het begin van een nijlpaard in karton, met een bordje als palet |
| solar-rover-bouwen | Het stappenblad open, de zakjes op een rij, nog niets gebouwd |
| tekenen-in-de-klas | Twee kinderen aan een tafel, de blaadjes nog bijna leeg |
| trots-bij-haar-robot | Trots naast het kartonnen robotmannetje dat rechtop staat |
| trots-met-lego-wagen | Trots met een lego-wagen met motor en batterijhouder |
| werken-aan-de-groene-tafels | Vooraan een zelfgemaakt bordspel van karton |

Wat Kim erbij vertelde: het schaakbord is een **Minecraft-schaakbord** waar de
kinderen gek op zijn. `plusklas-de-katteket` en `plusklas-mars-projecten` zijn de
voorbereiding van de **tentoonstelling van hun eindwerk**, met een volledig
uitgewerkte **maankolonie en marskolonie**. `patronen-tekenen` is **braintraining**:
met twee handen tegelijk hetzelfde patroon tekenen om de hersenen wakker te maken.
`schilderen-met-acryl` is de start van een **nijlpaard in karton**.

**Op bijna alle foto's staan kinderen herkenbaar in beeld.** Zonder gezichten
zijn: `werken-aan-de-groene-tafels`, `patronen-tekenen`,
`materiaal-uitgesorteerd`, `papieren-figuurtjes-knippen`,
`robot-van-karton-in-de-hand`, `karton-uittekenen`, `lego-robot-met-scherm`,
`solar-rover-bouwen` (een jongen van opzij) en `collage-project-plusklas`.

De zip opnieuw maken:

```
rm -f connectopia-fotos-werking.zip
zip -j connectopia-fotos-werking.zip *.jpg *.png
```

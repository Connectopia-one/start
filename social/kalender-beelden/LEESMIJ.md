# Beelden voor de social media kalender

Schermafbeeldingen van de website zelf, gemaakt op 23 september 2026, zoals de
pagina er op dat moment echt uitzag. Breedte 1200 px, hoog genoeg om er een
vierkant of een staand beeld uit te snijden.

| Bestand | Hoort bij |
| --- | --- |
| dag-01-winactie | Dag 1, de winactie van het oefenplatform |
| dag-05-wegwijzer | Dag 5, de wegwijzer voor ouders |
| dag-06-blog-autisme | Dag 6, blog over autisme bij cognitief begaafde kinderen |
| dag-07-externe-plusklas | Dag 7, de externe plusklas |
| dag-08-observatielijst | Dag 8, de gratis observatielijst |
| dag-11-14-15-young-engineers | Dag 11, 14 en 15, Young Engineers |
| dag-13-blog-leren-leren | Dag 13, blog over leren leren |
| dag-18-prikbord | Dag 18, het prikbord |
| dag-19-blog-diep-gedacht | Dag 19, blog over hoogbegaafde vrouwen |
| dag-21-waar-kan-je-terecht | Dag 21, de hele gids |
| dag-24-oefenplatform | Dag 24, het oefenplatform |
| dag-25-blog-zomer | Dag 25, blog over vakanties |
| dag-26-over-ons | Dag 26, het verhaal achter Connectopia |
| dag-28-vakantiekampen | Dag 28, de vakantiekampen |
| dag-29-voor-professionals | Dag 29, de pagina voor professionals |
| extra-startpagina | Vrij te gebruiken, de startpagina |
| extra-blog-overzicht | Vrij te gebruiken, het blogoverzicht |
| extra-aanbod | Vrij te gebruiken, de aanbodpagina |

Let op: op `dag-07-externe-plusklas`, `dag-28-vakantiekampen` en
`extra-startpagina` staan foto's van kinderen die al op de website staan. Wil je
dat niet op sociale media, snij dan het bovenste stuk van het beeld uit of kies
een ander beeld.

Bij een paar dagen zetten we geen schermafbeelding, omdat het beeld van jou moet
komen: de poster van de pluswerkingen en van Young Engineers staan al klaar in
`/mnt/project-files/pluswerkingen/` en `/mnt/project-files/young-engineers/`.
